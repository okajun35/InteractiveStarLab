# Project progress — 2026-08-30

Interactive Star Lab is ready for the English-only conversion checkpoint. The current work preserves the astronomy calculations, immutable Mission predictions, local fallback behavior, cloud persistence, WebMCP tools, Snapshot storage, and Observation Guide generation.

The application now uses English labels and messages throughout its user-facing screens, generated content, accessibility surface, and verification scripts. Japanese-only catalog fields have been removed from the application data and domain contracts.

Run `npm run build` and `npm run verify` before committing. `npm run verify:layout` additionally requires a working Playwright installation and Chromium.
